Magic Mayhem


Team: 3 developers   Genre: Arena PvP / Multiplayer
My Focus: Spell System, Status Effects, Wizard Classes

Magic Mayhem is a magic-based arena PvP game that I developed with two friends. Players can join a friend's lobby and choose from six different wizard types, each with their own abilities and playstyles. Players compete to get the most kills before the match ends, with the player with the highest kill count winning.
My primary contributions focused on the spell and status-effect systems. I designed and implemented six different wizard types and developed four status effects:

Bleed — applies damage over time.  Burn — applies fire-based damage over time.
Stun — temporarily stops the player.   Slow — reduces players speed.

I also worked extensively on the spell system, creating and implementing the spells used by the different wizard types.

Custom Renderer


Team: Personal Project   Genre: 3D Graphics / Rendering
My Focus: OpenGL Renderer, Level Loader, Shaders

Custom Level Renderer is a personal project where I utilized OpenGL to create a custom 3D level renderer. I created the scenes and levels in Blender and developed an object-oriented level loader to load the objects into my custom renderer.

The level loader reads a text file containing the object's transform information and name, then uses that information to load the objects into the renderer.

The renderer displays the objects in the viewport by passing the level's information to the vertex and fragment shaders through the use of a uniform buffer.

Zombies Zombies and More Zombies


Team: 3 developers   Genre: Survival / Defend the Point
My Focus: Enemy AI, Enemy Classes, Enemy Behaviors

Zombies, Zombies, and More Zombies is one of the first games that I worked on with two other developers. It is a defend-the-point style game where players must kill zombies to end each round while making sure the zombies don't destroy the objective. Players earn money from kills that can be used at the shop between rounds.

The game features four different types of zombies, each with their own behavior and purpose:

Base Zombie — standard enemy type.  Fast Melee — fast-moving enemy designed to quickly reach the objective.
Ranged — attacks the player from a distance.   Brute — a stronger enemy designed to withstand more damage.

Each enemy has a chance to drop health, armor, or ammunition for the player to use.

My primary contribution was developing the enemy AI system. I created a base EnemyAI class containing shared functionality and then created child classes derived from the base class for each of the four enemy types. This allowed me to reuse common enemy functionality while giving each type its own unique behavior.

Mouse Trapped

Team: Personal Project   Genre: Souls-like / Third-Person Action RPG
My Focus: Enemy AI, State Machines, Combat Systems

Mouse Trapped is a third-person Souls-like action RPG focused on exploration and deliberate combat. Players explore interconnected environments, fight different enemies, and manage health, stamina, attacks, guarding, rolling, and healing to survive encounters.

My primary contribution has been developing the enemy AI system. I created a state-machine system that allows enemies to transition between behaviors such as patrolling, chasing, attacking, guarding, and dying. I also developed a modular patrol system that allows enemies to follow multiple routes and switch between them.

The player also uses a state-machine system to manage actions such as movement, attacking, guarding, rolling, healing, staggering, and death.
